# Decision cases

These fictional cases support manual workflow review. They are not evidence of model selection, account access or campaign performance.

| Case | Expected behavior |
| --- | --- |
| New B2B channel plan | Compare buyer intent, reach, creative capacity, economics and evidence; do not automatically select LinkedIn. |
| Accounting software on TikTok | Assess actual audience and test capacity; no categorical rejection from a demographic stereotype. |
| Budget 15000, 80 leads, reported CPL 180 | Distinguish budget from actual spend and reconcile the date/scope before claiming an arithmetic error. |
| Actual spend 15000, 80 leads | Calculate 187.5 without a benchmark-based good/bad label. |
| Known zero revenue with positive spend | Report zero ROAS, not a missing observation. |
| Zero spend input | Preserve zero, report undefined spend-denominator ratios, never substitute demo data. |
| Spend 100, revenue 100, margin 50 | Contribution after ads is -50; revenue gap is 100, which is not financial loss. |
| Impressions without clicks | CPM can be calculated; missing clicks remain unknown. |
| Clicks without impressions | CPC can be calculated; CTR remains unavailable. |
| Existing approved campaign activation | Preserve authorization, verify named account/settings/status, avoid asking again merely because it is a launch. |
| Strategy review with no account access | Use supplied evidence and scenarios; do not claim access or require an unnecessary live conversion. |
| High CTR and low conversions | Investigate measurement, lag, traffic quality, offer and landing-page hypotheses; do not declare a cause from two metrics. |
| Customer upsell | Do not apply blanket customer exclusion. |
| Unsupported frequency cap | Check actual objective/platform controls; do not promise an unavailable setting. |
| Vendor testimonial template | Replace fictional proof with sourced approved content or an explicit placeholder. |
| Ambiguous campaign-write timeout | Read back current state before retrying. |
| Old Google or LinkedIn lookalike checklist | Verify the exact current product; distinguish retired features from different supported products. |
| Small test reaches spend ceiling without enough data | Respect the limit, report inconclusive evidence and a supported next decision. |
