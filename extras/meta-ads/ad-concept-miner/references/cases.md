# Fictional decision cases

These are hand-reviewed decision examples, not live platform or model tests.

| Request or evidence | Expected behavior |
|---|---|
| “Analyse these five competitor screenshots.” | Teardown supplied material and deliver a concept board. No acquisition, rendering or publication is necessary. |
| “Find active Australian clinic ads,” but only a restricted API tool exists. | Establish that tool's coverage. Use another available authorized public source or report the missing acquisition lane; do not silently substitute UK ads or invent results. |
| A UK-only commercial API query is proposed. | Resolve conflicting dated coverage evidence against the current contract or use another appropriate available source. |
| One advertiser has 18 near-identical variants. | Count distinct IDs and one advertiser; cluster with a reason. Record recurrence, not budget or performance. |
| Six advertisers share a template. | Record cross-advertiser recurrence and possible common agency/template origin. No “market-validated” label. |
| A political ad includes a spend range and impression range. | Keep the scoped ranges and period if relevant. Do not derive conversions, ROI or profitability. |
| A page exposes only a headline behind a modal. | Produce a text-only record with visual fields unavailable. Do not invent a screenshot teardown or use page metadata as proof of the creative. |
| A result contains a token-bearing snapshot or pagination URL. | Keep credentials inside the authorized client; write only safe IDs/references. Do not pass the raw URL to another agent or report. |
| Pagination repeats the same cursor and the sample has 12 records. | Stop, deduplicate and label the sample partial with the repeated-page reason. Do not report a complete market census. |
| The provider wait would exceed the remaining collection budget. | Record a partial result or resumable missing step; do not ignore the limit or hammer retries. |
| The user asks to combine their account's metrics with public examples. | Use the performance owner and the explicitly authorized account scope. Keep private metrics separate and label the basis of any conclusion. |
| “Create three on-brand variations from these concepts.” | Read current brand/offer/copy sources, create original executions with appropriate assets, render through the active owner and inspect the result. Do not ask again for permission to perform that requested local creative work. |
| A reference depends on competitor testimonials or a refund promise. | Record the observed pattern for research; produce a different, grounded execution using your own approved claims and permitted assets. |
| A US sample is used to inform an Australian brief. | State the source market and uncertain transferability, then localize the requested brief. Do not represent the sample as Australian evidence. |
| A repeated run would reuse last week's directory. | Create a new run identity; preserve the previous evidence and keep public/private records separate. |
