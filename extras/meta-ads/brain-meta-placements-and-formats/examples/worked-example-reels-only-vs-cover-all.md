# Worked example: one vertical clip and a Reels-only proposal

Illustrative response, not evidence of a live campaign test or account change.

**Request:** I have one vertical clip for a city workshop campaign. Should I restrict delivery to Instagram Reels to avoid wasting budget on Feed? Which exports do I need?

**Response:** A vertical clip alone does not establish that Reels-only will produce better workshop leads. Start by previewing it on the eligible placements and checking whether the message remains readable. If broader delivery fits your campaign brief, retain that option and adapt the asset where a crop damages it. Choose Reels-only when the campaign has a specific placement requirement or as a defined experiment.

For this clip, prepare a 9:16 version for the Reels preview. A 1080×1920 export is a convenient production canvas, not a universal eligibility guarantee. Keep the speaker, offer details and captions clear of interface overlays. Listen to the audio and also check that the message can be understood with sound muted. Meta's [Reels guidance](https://www.facebook.com/business/ads/facebook-instagram-reels-ads) recommends vertical creative, audio and key elements inside safe zones, and describes both automatic and manual placement choices.

Inspect the Feed preview before deciding on another export. A 4:5 adaptation may make better use of the available space; retain a working square version if it suits the selected format. Do not discard an asset merely because an old example calls square retired. Check the actual placement and format requirements before choosing dimensions, duration, file type or size.

A centered composition can make adaptation easier, but a central square cannot guarantee safe rendering everywhere. Check the actual crop, text size, interface overlays and CTA in every intended placement. Use placement customization where available; create a separate adaptation if cropping loses meaning. A horizontal source can also be reframed successfully when the content supports it.

If you want a Reels-only experiment, record the question, eligible audience, qualified-lead measure, observation window and authorized spend before changing delivery. Inspect the controls available in this account and select the intended placements. Check any expansion or limited-spend option and read the saved configuration back. Do not infer a hard exclusion from an old checkbox label or API recipe. Verify delivered placement breakdowns after an authorized launch.

Compare qualified leads and downstream outcomes alongside spend. A placement receiving more budget or fewer last-click conversions is not, by itself, proof that excluding it improves the campaign. A controlled comparison can address that question when sufficient data and budget are available.

**Proposed next step:** preview the current clip and list only the adaptations it actually needs. This response makes no campaign edits, sets no new budget and claims no performance result. Source-level limits are recorded in [primary sources](../references/primary-sources.md).
