# CTA Engine

The last slide converts attention into something you keep. Most CTAs fail for
one reason: they ask for three things at once and get none. This skill forces
one goal per post and writes the ask for exactly that goal.

If `~/.claude/brand-kit.md` exists, read it first; its standing CTA is the
default goal when the user has no preference.

## Pick the goal first

Ask one question: what should this post produce? One of:

| Goal | The ask | When to pick it |
|---|---|---|
| Saves | "Save this for your next post" | Reference content, lists, how-tos |
| Follows | "Follow for the next one" plus what is coming | Building an audience, series content |
| Comments | A comment keyword (below) | You have something to send people |
| Shares | "Send this to the person who needs it" | Relatable pain, team content |
| Clicks | Link in bio, named | You have a page worth the friction |

One goal. If the user wants two, the second one goes in the caption, never on
the slide, and you say so.

## Comment keyword CTAs

The strongest carousel CTA when there is a deliverable, because every comment
is reach and a DM conversation. Rules learned the hard way:

- One word, upper case, easy to type: SKILLS, GUIDE, TEMPLATE.
- Pick a word people would not type by accident in a normal comment, or your
  DMs fire on the wrong people. PRICING is safe; NICE is not.
- Say exactly what commenting gets them and that it arrives by DM: "Comment
  SKILLS and I'll DM you all five."
- Only run it when the DM automation is actually live. A keyword nobody
  answers burns trust with everyone who typed it.
- Repeat the keyword line as the last line of the caption, word for word.

## Writing the slide

Slide copy caps at 20 words: the ask, the reason, nothing else. The reason is
what they get, not what you want. "Follow so you never lose these" beats
"Follow me". Never thank them for reading on the CTA slide; it spends the
slide on politeness instead of the ask.

## Output format

The chosen goal and why in one line. The CTA slide copy. The caption's closing
lines including the keyword line when there is one. Then one alternative CTA
for a different goal, marked clearly as the option not taken, so the user sees
the trade they made.
