## What the experts agree on

1. **Peak alignment is THE pro/amateur divide.** Place the SFX waveform's peak exactly on the cut point, or on the frame with the most motion blur mid-motion. Stated independently by Joseph | Video Editing (twice), Gavin Herman ("the difference between pro and amateur"), Film Editing Pro ("align the apex to your edit, add markers"), Tim Runia, Jason Yadlovski.
2. **Small consistent palette, repeated — never a new sound per element.** Joseph: pick 2-3 sound families and reuse; 50-60 sounds in a lifetime library. Herman Huang: one sound style/pack per project. NOX CUT: duplicate/stretch/break ONE sound into variants. Abhay: vary pitch/speed slightly on each reuse so the identical file doesn't grate.
3. **Motion gets a whoosh, emphasis gets its own distinct sound.** Learn By Leo's base rule; Joseph splits "movement" (whoosh) vs "texture" (clicks/UI/bells); Abhay: silent motion feels "hollow and fake".
4. **Restraint beats coverage.** SFX mark IMPORTANT moments only — a whoosh on every cut exhausts viewers in 2-3 minutes (Abhay); "if you try to make every moment special, none of them will be special" (Film Editing Pro); risers without payoff lose their power (Herman Huang).
5. **The graphic/text appears at the same instant the phrase is spoken.** Early or late "feels weird" (Marcus Jones). Zoom punches, beat drops, and topic shifts all land ON the line (Herman Huang, Learn By Leo).
6. **Intros = riser/build into an impact-reveal, layered.** Riser→impact is the named intro pattern (NOX CUT citing Dhruv Rathee; Bhavya Shah; Tim Runia's own hook stacks riser+whoosh+impact+click). One sound alone is amateur — stack 3-5 layers (Artlist).
7. **Silence is a transition tool.** Riser → smash cut → silence "hits way harder" (Tim Runia); impact needs preceding quiet; deliberate quiet passages make the return land (Jacob Nordin).
8. **Mix discipline: voice on top, SFX just audible, music quietest.** SFX "should not prick" (NOX CUT). Targets across sources: dialogue ~-12dB / -14 LUFS, SFX -10..-30dB, music -20..-30dB, nothing peaking; check TRUE PEAK not just LUFS (Greg Edits Video).

## Named frameworks & methods

- **Joseph's 3-step order**: (1) sound-design all MOVEMENT (whooshes), (2) add TEXTURE to everything else (clicks/gears/UI/bells), (3) optionally add EMOTION (risers/hits) — step 3 skippable.
- **Joseph's element map (short-form)**: double-click = text popups; digital click + bell = glowing elements; highlighter-scrape = line/rectangle draws; glitch/"data" = flickering text and counters.
- **NOX CUT's element map**: pop = text pop-ups; paper = highlighted stats; camera-flash = white flash frames; whoosh/smush = scroll/zoom; info-UI = text reveals.
- **Tim Runia's 4 whoosh flavors**: heavy/deep = big or close objects; light/high = fast or comedic; whip = whip-pans; soft wind = aerials.
- **Tim Runia's pivot combo**: riser → smash cut → silence (hard topic pivot); riser + impact (reveal).
- **Gavin Herman's one-sound-three-sounds**: cut a whoosh at its inflection = impact; reverse it = riser. Reverse the outgoing track's last beat = bridge riser between songs.
- **Jason Yadlovski's click-riser**: duplicate a click and pitch it up incrementally = a riser built from clicks for text-pop sequences. Whoosh front starts BEFORE the cut, tail after = merged scenes.
- **Jacob Nordin's J/L-cuts**: next topic's audio fades in before its visual (J) or previous audio lingers (L) — the tool that makes topic cuts feel motivated.
- **Kallaway's verbal transition formula**: context lean → one contrast-word "stun gun" (but/however/yet) → contrarian snapback; staccato sentences at transitions.
- **Radio edit first** (Gaku Lange, inferred): mark the music's beat-drops before touching visuals; place major transitions at those points.

## Contrarian / disputed takes

- **Whoosh-per-cut**: NOX CUT sound-designs nearly every animation move; Abhay and Film Editing Pro say per-cut whooshes exhaust the viewer. Reconcile: density scales with how animated the content is — motion-graphic-heavy explainers tolerate more, talking-head reels need restraint.
- **Trending platform audio**: standard growth advice, but Vanessa Lau flags mute/licensing/ads risk — licensed or owned sound wins for business content.
- **Flashy transitions**: RyanNangle teaches elaborate zoom-through/masked transitions; Dylan argues "if someone says 'that editing was cool', you missed the mark" — emotion first. Ben Claremont prefers clean hard cuts over preset transitions entirely.

## Execution playbook

- IF placing any SFX THEN align its waveform PEAK to the cut frame or the most motion-blurred frame — not the cue's start frame (Joseph, Gavin Herman, Film Editing Pro). For generated cue sheets: trim leading silence so peak ≈ file start, or offset the cue a few frames early.
- IF an element pops on screen THEN it sounds AS the word is spoken — never before, never after (Marcus Jones). Word-frame timing comes from the transcript.
- IF designing a reel's palette THEN 4-6 sound families max, reused all video: movement=whoosh (sized to the motion), text/UI=click, emphasis/glow=ding/bell, mistake=buzz/error, pivot=riser→impact (Joseph, Learn By Leo, Herman Huang).
- IF a sound repeats many times THEN vary pitch/speed ±5-10% per instance so it never plays identically twice (Abhay, Jason Yadlovski's pitch-stepped clicks).
- IF a hard topic pivot THEN riser → cut → beat of silence before the next line (Tim Runia); IF a reveal THEN riser + impact together.
- IF two motions at once THEN layer a small whoosh under a big whoosh — one sound per event group, not per element (Joseph, NOX CUT).
- IF the moment is soft THEN under-treat it; save the full stack for the climax (Film Editing Pro).
- Default mix: voice on top (~-12dB / -14 LUFS), SFX just audible -10..-30dB ("should not prick" — NOX CUT), music -20..-30dB, true peak ≤ -1.5dB (check true peak, not just LUFS — Greg Edits Video).
- Pre-flight: transcript beat list written → every named subject has a visual+sound at its word frame → palette table (element type → sound family) → peaks aligned → mix levels → listen on phone speaker.
- Failure modes: whoosh on every cut (exhausts in 2-3 min — cut density); same file repeated identically (vary pitch); riser with no payoff (delete it); all tracks at 100% (duck SFX/music); LUFS fine but true-peak clipping (limit).
