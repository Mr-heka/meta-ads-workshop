# Slide Builder

A carousel is not a document cut into squares. Each slide is one screen, read in
at a glance before choosing whether to read further. This skill turns raw
material into a slide map where every slide earns the next swipe.

If `~/.claude/brand-kit.md` exists, read it first and obey its voice, audience,
spelling and banned-words rules.

## Brand and source first

Before selecting the hook or slide count, recover source locations, meaning, selective IP decisions and the proposed audience/business application. Keep actual facts separate from invented examples or untested benefits. A generic brand-kit file does not override a selected personal authority. For each brand, use its current source and identity contract.

## Input

Any of: a topic plus a chosen hook, an article or blog post, a voice-note
transcript, rough dot points. If there is no hook yet, run the material through
/hook-writer first and let the user pick, because the hook decides what the
slides must prove.

## The shape

An eight-slide arc is one useful starting point after source review. Adapt the count and structure to the complete idea and requested output; do not pad, split a necessary explanation or add a promotional ending just to fill this pattern. Example arc:

| Slide | Job | Word cap |
|---|---|---|
| 1 | The hook, from /hook-writer | 12 |
| 2 | The stakes: why this matters to the reader today | 25 |
| 3 to 6 | The value: one point per slide, no exceptions | 30 each |
| 7 | The recap: all points on one screen, scannable | 35 |
| 8 | The CTA, from /cta-engine | 20 |

Give each slide one clear purpose. Related evidence, qualifications and a meaningful visual can share that purpose. Preserve context; do not mechanically split every sentence containing “and”. A CTA requires a real, relevant next action and delivery path.

## Writing the value slides

- Lead each slide with the point, then support it. Never build up to it.
- Use concrete actions such as "compare both drafts against the source". Quantified benefits need actual evidence; never invent a time saving to strengthen a hook.
- Each slide's last line should make the next slide necessary. Numbered points
  do this for free.
- Write slide text, not captions: sentence fragments are fine, filler is not.

## Output format

The full slide map as a table: slide number, its job, the exact copy, and a one
line visual note (what the slide shows, not how to design it). Then the post
caption: 2 or 3 sentences restating the promise, no link, ending with the
comment keyword line if /cta-engine produced one.

Present the concrete sequence and unresolved meaning/CTA decisions for the requested chat checkpoint. Use copy-editor or cta-engine only where their review solves a real issue. Do not render the full deck while a required content approval is pending.
