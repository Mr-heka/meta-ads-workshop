# Higgsfield video prompting observations

Use this reference when its evidence helps the task. For writing a prompt or operating
Higgsfield, start with the `higgsfield-connector` skill in this kit. For Higgsfield's own prompt cookbook and sub-skills, see Higgsfield's published CLI skill material at https://github.com/higgsfield-ai/cli.
This brain adds source context; it does not replace that current workflow.

## Make the shot clear

Identify the intended subject, action, camera, look and sound. With an existing start
frame, describe the intended change and anything that must remain recognizable.
For text-to-video, describe the scene that has not been supplied visually. Choose the
input method for the brief and selected tool; an image-first approach is useful for
some continuity tasks, not a prerequisite for every clip.

Keep reference roles explicit: identity, product appearance, composition, location,
motion or sound. Use actual attached asset handles only where the selected interface
supports them. A name in a prompt does not upload or bind an asset. Inspect the output
for drift rather than claiming the reference locks it.

For sequences, use a shot list or timed beats when that clarifies action and the tool
supports it. Keep meaningful geography, exact dialogue and required visual facts.
Do not remove a requested crowd, fast action or camera move solely because a creator
reported difficulty. Diagnose the actual result and propose alternatives openly.
