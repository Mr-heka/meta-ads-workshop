## The one-paragraph version

Pick the model first: **Nano Banana Pro** for photoreal + text + edits, **Higgsfield Soul / Soul 2** for trained-character (Soul ID) work, **GPT Image** for multi-reference composites. Build the prompt from six slots — **subject + action + environment + art style + lighting + details** — where "art style" is your camera/lens/aperture and "lighting" names the direction. Be specific (real camera bodies, named light, "sharp focus on the eyes"). To edit, lead with an action word (Add/Change/Make/Remove/Replace). Lock identity with Soul ID or reference images. Generate 4, pick the best, then make surgical in-context edits rather than re-rolling.

## What the experts agree on

- **One formula underlies everything:** subject + action + environment + art style + lighting + details, each slot specific. (AI Master, Taylor Bay Studios — independent, near-identical)
- **Camera/lens/aperture is the look lever.** Naming the body and glass ("85mm on medium format," "f1.4," "macro lens for sharp detail") measurably shifts output. (AI Master, Artturi Jalli, Theoretically Media)
- **Specific lighting beats "nice lighting"** — name the direction and quality ("dramatic side lighting from camera left," "natural window light"). (AI Master)
- **Nano Banana Pro is the consensus best image model** for photoreal, reference fidelity, and in-image text. (DGI Kaos, metricsmule, Rourke Heath)
- **Lock identity deliberately** — Soul ID (stay on the Soul model), reference images, or expression sheets; restate accessories. (Artturi Jalli, DGI Kaos, Jack Vs. AI)
- **Edit with action words and lighting anchors** — Add/Change/Make/Remove/Replace; "maintain natural lighting on the subject" for background swaps. (Taylor Bay Studios, AI Master)
- **Generate 4 and cherry-pick; test low-res then upscale.** (DGI Kaos, Rourke Heath)
- **Suppress AI tells** — "no text on clothing," "no shadows" for product, "candid / looking to the side" to kill stiff poses. (DGI Kaos, AI Master)

## Named frameworks & methods

- **Six-component formula:** subject + action + environment + art style + lighting + details. (AI Master, Taylor Bay Studios)
- **Five editing action words:** Add, Change, Make, Remove, Replace. (Taylor Bay Studios)
- **5-input creative-director system → JSON prompt:** purpose, audience, subject, brand rules, optional reference → system prompt writes the JSON. (Dylan Davis)
- **JSON prompting** for surgical, repeatable edits on Nano Banana Pro. (WealthWise, Dylan Davis)
- **Subject recipes:** portrait / product / architecture / landscape / street / text / abstract / style-transfer each have a fixed slot pattern. (AI Master)
- **Reverse-engineer meta-tokens:** feed a great image to ChatGPT and reuse the camera/lighting tokens. (metricsmule, Jack Vs. AI)
- **Higgsfield features:** Cinematic Cameras, Mood Board, Shots (9 angles), Skin Enhancer, Relight, Topaz Upscale, Canvas (multi-model compare), Cinema Studio Cast.
- **Aspect ratio:** 16:9 hero/thumbnail, 9:16 reels, 1:1 feed, 21:9 cinematic anamorphic. (Higgsfield AI, Theoretically Media)

## Contrarian / disputed takes

- **Keyword-stuffing vs context-rich prose.** Dylan Davis (citing Google): Nano Banana Pro needs rich context, not jargon. AI Master / Taylor Bay still teach explicit camera/lighting keywords and report them working. Reconcile: keywords help, but a complete description of intent matters more on reasoning-heavy models.
- **Prompt enhancer on or off.** Higgsfield AI: on by default for Soul 2 (expands bare prompts). DGI Kaos / Jack Vs. AI: off, because it edits your wording and removes control. Use case decides.
- **Inpaint brush reliability.** Artturi Jalli rates Higgsfield's inpaint poor and re-prompts instead; AI Master gives an inpaint recipe that works when you describe the fill. Yaroflasher rates inpaint as the one editing tool that *does* work well. Mixed — test on your image.
- **Higgsfield vs MidJourney.** Jack Vs. AI: Higgsfield for photoreal, MidJourney for surreal. Use both — MidJourney for environment refs, Nano Banana Pro for character consistency.

## Execution playbook

- IF starting any image prompt THEN fill all six slots: subject + action + environment + art style + lighting + details (per AI Master)
- IF the job is photoreal, in-image text, or reference fidelity THEN use Nano Banana Pro (per DGI Kaos)
- IF the image needs a recurring trained character THEN stay on Soul / Soul 2 with Soul ID, switching models drops the character (per DGI Kaos)
- IF editing an existing image THEN lead with Add, Change, Make, Remove, or Replace and name the exact element (per Taylor Bay Studios)
- IF swapping a background THEN add "maintain natural lighting on the subject" and preserve original shadows (per AI Master)
- IF an image is 90% right THEN make surgical in-context edits in the same chat, never re-roll (per Dylan Davis)
- IF output looks AI THEN suppress the tells: "no text on clothing", "candid, looking to the side" (per DGI Kaos, AI Master)
- IF you wrote a precise prompt THEN turn the prompt enhancer off so it can't rewrite you (per Jack Vs. AI)

Defaults: Soul ID trains on 20-31 photos, ~5-60 min (Artturi Jalli). Generate 4 per batch, ~2 credits (DGI Kaos). Test at 720p/2K, upscale keepers to 4K (Rourke Heath). Shots ~4 credits, Skin Enhancer ~4 credits, Topaz upscale 2x/4x/8x (DGI Kaos, Artturi Jalli). Aspect: 16:9 hero, 9:16 reels, 1:1 feed, 21:9 cinematic (Higgsfield AI). Mood Board: 20-30 same-style images (Artturi Jalli). Expect 5-10 attempts to nail a shot exactly (Artturi Jalli). Prompt discipline ~2,800 chars (Theoretically Media).

Pre-flight:
- Pick the model first: Nano Banana Pro for photoreal/text, Soul 2 for Soul ID, GPT Image for multi-reference composites
- Set the aspect ratio before generating (Higgsfield AI)
- Draft all six slots with a named camera body, lens, and light direction (AI Master)
- Identity matters? Load the Soul ID tag or 1-4 reference photos, restate accessories (Artturi Jalli, Jack Vs. AI)
- Decide enhancer on or off: on for bare prompts, off for precise ones (Higgsfield AI vs DGI Kaos)
- Confidential client material? Keep it out: Higgsfield terms can use generations in promotion (Yaroflasher)

Failure modes:
- Vague prompt ("woman in cafe"): fix by filling every slot with specifics (AI Master)
- Vague edits cause face/body drift: fix with an action word plus the exact element, name existing colors (Taylor Bay Studios)
- Background swaps read fake: fix with the lighting anchor and preserved subject shadows (AI Master)
- Re-rolling a near-perfect image burns credits: fix with in-context surgical edits (Dylan Davis)
- Mixed styles in Mood Board break it: keep all 20-30 images in one style (Artturi Jalli)
