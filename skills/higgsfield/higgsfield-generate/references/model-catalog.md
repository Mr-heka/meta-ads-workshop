# Map the selected model to its schema

Higgsfield's own model guide (published CLI skill material at https://github.com/higgsfield-ai/cli) owns selection and current recommendations. Preserve an explicitly chosen model. This file replaces the old ranking table with an execution check.

From version-matched help, identify catalog listing and model inspection. Official docs describe `higgsfield model list` and `higgsfield model get MODEL_ID --json`; treat `MODEL_ID` as a value resolved from the selected catalog, never a display-name guess. Inspect the unfiltered catalog when a targeted search might have missed a user-named model. An inaccessible catalog means availability is unknown, not that the model does not exist.

For the chosen model, record the safe schema identity and check required inputs, flag spelling, media roles/counts, enums or ranges, duration, aspect ratio, resolution, audio behavior and response shape. Keep model settings outside the creative prompt. Do not assume underscores/hyphens or older IDs are interchangeable without the selected version's evidence.

The historical snapshot includes image generation, video generation, Marketing Studio and `brain_activity` video-in/text-out analysis. These are examples of operation types, not current recommendations. A provider analysis result does not establish measured human attention or business outcomes. See [sources](../SOURCES.md).
