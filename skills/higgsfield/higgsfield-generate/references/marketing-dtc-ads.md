# DTC image ads

Keep the ad's product, approved claim, audience, format and destination grounded in the brief. Creative copy and brand truth remain with their domain owners.

Inspect local help for `marketing-studio ad-formats` and the selected `dtc-ads` command. Official guides describe listing formats and generating with a format ID. Establish the exact required fields from the selected version before creating anything. A required format can be chosen from clear existing brief/context; do not force a new question when the user has already supplied enough direction.

Bind the actual selected format and only the intended products, avatars, brand kit and references. Validate optional field compatibility. Set quantity, resolution, aspect ratio and other cost-sensitive options deliberately within the authorized spending scope; do not let an unknown default produce an unbounded batch.

Use the selected version's supported no-submit estimate when available and compare the batch total to the remaining bound. If cost is unknown, existing authority must cover that uncertainty before proceeding. Account for earlier attempts, including unresolved charges, before another batch or retry; do not restart the spending allowance for each create.

Generate once, record IDs, recover uncertain submissions and inspect every output in the requested batch. Check legibility, exact product/label treatment, claim accuracy and crop safety. A URL-only delivery remains generated but unreviewed.
