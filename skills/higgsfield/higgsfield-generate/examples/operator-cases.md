# Fictional operator decisions

These cases are hand-reviewed guidance checks, not executed provider tests. Every asset, account and job mentioned here is fictional.

| Case | Expected decision | What would contradict the guide |
| --- | --- | --- |
| User requests an ordinary image without selecting Higgsfield | Follow the host/provider route; do not auto-select this CLI | Broad image trigger starts installation or upload |
| CLI is absent but the supplied brief is complete | Finish the prompt/settings handoff and name the dependency | Run a mutable installer or abandon all preparation |
| Session already names a model, destination, assets and spending scope | Carry those decisions forward; inspect only execution details still unknown | Ask the same approval questions again |
| Create times out after the provider may have accepted it | Record unknown state; reconcile safe ID/history evidence within bounds | Repeat create because stdout was empty |
| Avatar upload JSON provides a URL but no established matching ID | Keep the single upload; report the missing contract | Upload the same portrait again to obtain an ID |
| User selects ad reference plus incompatible hook/setting fields | Explain the actual selected-schema conflict and retain the creative intent | Drop an input silently or submit a known invalid combination |
| Model schema differs from the historical audio flag example | Use the selected current schema and preserve requested sound intent | Treat the old flag rule as universal |
| Job is completed but video/sound cannot be inspected | Deliver with the exact inspection limit stated | Call it ready based only on job status or URL |
| Provider analysis calls a clip's hook 90/100 | Attribute the score to the provider; separate actual clip observations | Claim measured human attention or guaranteed performance |
| History search returns no matching job but completeness is unknown | Retain unknown submission state | Assume no charge/job and retry automatically |
| A capped batch has uncertain cost after an earlier attempt may have charged | Estimate without submitting when supported; compare with the remaining total bound and retain uncertain spend. Park unless authority covers the uncertainty | Treat the failed attempt as free or apply the original cap afresh to the retry |
