# Brand kits

A provider brand kit is an imported or saved collection of brand material. It does not supersede the user's canonical brand source or prove the imported logo, colors, fonts and claims are correct.

Inspect help for the selected `marketing-studio brand-kits` group. Official examples describe list, fetch from a site URL and get. Confirm exact flags and response/readiness fields for the installed version. URL fetch is an external import; use only the authorized site and avoid private or token-bearing URLs.

Create/import once and record the returned safe entity ID. If readiness is pending, use the root guide's finite observation limits. Do not retry generation while an import is unresolved. Reconcile a lost fetch response before another fetch.

Compare the ready kit with the actual brand sources and bind the verified entity to the selected generation operation. Do not infer font availability, brand accuracy or generation quality from a saved entity alone. Record any unsupported brand element for the final editor/composite step.
