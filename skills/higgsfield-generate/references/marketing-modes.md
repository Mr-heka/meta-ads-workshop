# Marketing Studio modes

Select a mode for the brief, then validate its actual slug and compatible inputs on the selected model/version. Do not hard-code a permanent default from an older catalog.

Historical examples include UGC, how-to, unboxing, product showcase/review, TV spot and virtual try-on. These names describe creative approaches; they do not establish current availability, duration, aspect ratio, resolution, price or quality.

Check whether the chosen mode accepts hook/setting entities, an ad reference, product/web-product fields, avatar inputs, and audio. The original hook/setting whitelist differed by mode. Retain that validation step without treating the old whitelist as current truth. An image Marketing Studio model need not accept video-only setup fields.

Keep reference-driven and hook/setting-driven paths distinct when the selected schema makes them exclusive. If the requested combination is unsupported, explain the concrete conflict and propose the closest intent-preserving configuration. Never silently discard selected inputs or switch model merely to make a command run.
