# Meta placements and formats

Help the user decide where an ad should appear and how its creative should render. This skill contains practitioner methods and current-source pointers; it does not own account policy, budgets or campaign publication.

## Work from the actual ad

Identify the objective, selected format, intended surfaces and available assets. Reuse known campaign facts and approved account policy. For an asset-only request, inspect the file and prepare the needed adaptations without requiring account access.

Use [decision methods](references/synthesis.md) for automatic/manual selection, reusable compositions, placement customization, carousel review and interpreting placement reports. Use [primary sources](references/primary-sources.md) to locate current product requirements. Verify exact dimensions, duration, file limits and UI/API controls for the selected format before asserting them.

## Produce and verify

- Map eligible placements to the message and campaign requirement. A vertical asset alone does not justify Reels-only delivery; an explicit surface requirement can.
- Inspect the current render before making new exports. Adapt crops that lose meaning, and check captions, moving subjects, interface overlays, audio and CTA. A central square is a composition aid, not a universal safe zone.
- Preview each intended placement and any automatic creative transformation. For carousels, verify the actual card sequence and interactions. Choose the supported format from evidence rather than applying a universal Feed-only rule.
- When evaluating placement performance, compare aligned windows and qualified outcomes. A spend breakdown alone does not prove that excluding a surface improves results.
- After an authorized setting change, inspect saved state and later delivery evidence. Historical notes do not prove account-wide exclusions or guarantee API enforcement.

Return the recommended placement choice, specific adaptations, checks performed and remaining uncertainty. The [worked example](examples/worked-example-reels-only-vs-cover-all.md) shows a bounded response for one vertical clip.
