# Worked decision scenarios

These are illustrative responses, not reports of live account tests. They demonstrate the rebuilt guide's application to two common questions.

## A retargeting list appears to be ignored

**Request:** Meta keeps ignoring my custom audience on the retargeting ad set. Should I turn Advantage+ audience on and let it run?

**Response:** First establish whether the campaign must stay within that audience. If warm-only delivery is an approved requirement, preserve it while checking the saved audience configuration and reporting definitions. Turning on more expansion would not resolve that requirement.

Inspect the actual workflow to determine whether the list is a suggestion or a control. Compare the saved inclusion/exclusion settings with the intended list and check its freshness, matching limitations and result definitions. An unexpected returning-customer or prospecting breakdown does not, by itself, prove the delivery system ignored a hard boundary.

If the required restriction is available, prepare the exact change and perform it within existing authorization, then read the saved state back. If it is unavailable in this workflow, report the constraint and identify a supported setup that can meet the brief. Do not reproduce a historical toggle recipe or use value rules as a guaranteed age or audience restriction.

If broad acquisition is instead allowed, define a separate comparison with aligned creative, qualified outcomes, budget and observation window. The inherited creators report different results; those reports do not predict the result here. No account policy or budget has been changed by this answer.

## A claim that every ad set needs 20 creatives

**Request:** Everyone says I need 20 ads per ad set now. Is that real?

**Response:** It is an attributed practitioner recommendation in this collection, but it is not established here as a universal requirement. The [Meta engineering source](../references/primary-sources.md) explains retrieval capacity, not a per-ad-set production quota.

Plan from the concepts worth testing, production capacity, budget and useful observation window. If you have a few distinct, supported ideas, test those without padding the set to reach 20. If a larger portfolio serves the audience and can be evaluated, the count alone is not a reason to reduce it.

Label concepts separately from variations so a result can teach you something. Ordinary delivery may concentrate spend; an ad that receives little delivery is not necessarily a failed idea. Use a supported controlled experiment when the question needs a fair variant comparison, and inspect its actual metric and allocation settings.

A practical next step is to inventory the current ideas, identify the most useful unanswered question and propose the smallest test that can answer it within the authorized budget. This does not claim that visually similar ads literally collapse into one auction entry or that any creative count guarantees performance.
