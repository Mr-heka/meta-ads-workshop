# Primary platform evidence

[Meta's Andromeda engineering article](https://engineering.fb.com/2024/12/02/production-engineering/meta-andromeda-advantage-automation-next-gen-personalized-ads-retrieval-engine/) was published on 2024-12-02 and read during this September 2026 rebuild. It describes retrieval before subsequent ranking and infrastructure for a larger pool of eligible ads. It does not prescribe an advertiser's creative count, campaign structure or budget-change schedule. Those are separate operational decisions.

Do not convert reported model capacity into inference speed, treat selected-segment system gains as an account forecast, or infer that audience controls no longer matter. GEM and Andromeda are not established as interchangeable by this article.

The article's linked Advantage+ product page could not be retrieved in this check. Exact audience boundaries, placement exclusions, creative testing defaults, value-rule ranges, attribution choices and API fields remain subject to current documentation and actual account inspection. A failed public fetch does not establish that a feature is absent.

[Meta's Reels product guide](https://www.facebook.com/business/ads/facebook-instagram-reels-ads) was also retrieved and describes placement choices and creative adaptation. Use the placements skill for that surface. Neither public page establishes the current configuration of any Selr ad account.
